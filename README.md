# fourSTL Position Marker

## Descrizione

fourSTL Position Marker è un'applicazione Android progettata per consentire agli utenti di salvare e gestire le proprie coordinate geografiche (waypoint) su una mappa offline. L'app è ideale per escursionisti, viaggiatori e chiunque abbia bisogno di tenere traccia di luoghi specifici senza una connessione Internet.

L'applicazione è sviluppata in Kotlin e utilizza Jetpack Compose per un'interfaccia utente moderna e reattiva. Le mappe offline sono gestite tramite la libreria MapsForge, con dati forniti da OpenStreetMap.

## Funzionalità Principali

- **Salvataggio Posizione GPS**: Salva la tua posizione attuale con un semplice tocco.
- **Mappe Offline**: Utilizza mappe offline per la navigazione senza connessione dati.
- **Gestione Waypoint**: Visualizza, gestisci ed esporta i tuoi waypoint salvati.
- **Nessuna Connessione Richiesta**: Tutta le funzionalità principali operano offline.
- **Esportazione Dati**: Esporta i tuoi waypoint in formato JSON per backup o condivisione.

## Tecnologie Utilizzate

- **Linguaggio**: Kotlin
- **UI**: Jetpack Compose
- **Mappe**: MapsForge (con dati OpenStreetMap)
- **Architettura**: MVVM (Model-View-ViewModel)
- **Asincronia**: Kotlin Coroutines

## Installazione

Per compilare ed eseguire il progetto, avrai bisogno di Android Studio. Clona il repository e apri il progetto in Android Studio. Le dipendenze necessarie verranno scaricate automaticamente da Gradle.

```bash
git clone https://github.com/tuo-username/fourSTLPositionMarker.git
```
